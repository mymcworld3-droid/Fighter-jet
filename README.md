# SKYWARD｜3D 戰鬥機模擬器

以瀏覽器與 WebGL 製作的輕量飛行模擬器，可在手機、平板和電腦使用。飛越海島與機場，調整推力與視角，碰到地面或海面時可重新起飛。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 左側搖桿向上／下 | 抬高／降低機頭 |
| 左側搖桿向左／右 | 左／右轉，戰機同步傾斜 |
| 推力滑桿 | 調整引擎推力與速度 |
| 切換視角 | 切換戰機後方與機首視角 |
| W/A/S/D 或方向鍵 | 與搖桿相同的飛行控制 |
| V / R | 切換視角／重新開始 |

搖桿回中時機翼會逐漸擺平，機頭角度會維持，可反向推搖桿調整。這是偏向易操作的簡化飛行模型，並非真實飛行訓練工具。

## 執行

不需安裝套件。在專案根目錄啟動任意靜態網頁伺服器，例如：

```sh
python3 -m http.server 8080
```

在瀏覽器開啟 `http://localhost:8080`。也可部署到 GitHub Pages 或其他靜態網站服務。瀏覽器支援 WebGL 時使用硬體加速；無法使用 WebGL 時則改以 Canvas 進行 3D 投影，效能會依裝置而異。程式與 3D 場景不依賴外部套件；介面字型在連線時會自動載入，無網路時使用系統字型。

執行飛行操控測試：

```sh
npm test
```

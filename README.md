# SKYWARD｜3D 戰鬥機模擬器

以瀏覽器製作的輕量飛行模擬器，可在手機、平板和電腦使用。飛越海島、雪山、沙漠峽谷和火山島，尋找有摩天輪與雲霄飛車的樂園，也可以穿越飛行環。調整推力與視角、發射螢光曳光彈，並可看到隨戰機移動的尾氣。加速時，第三人稱鏡頭會往後拉，場景的拉伸與風切效果會隨實際速度變化。碰到地面或海面時可重新起飛。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 左側搖桿向上／下 | 抬高／降低機頭 |
| 左側搖桿向左／右 | 左／右轉，戰機同步傾斜 |
| 多人連線 | 建立房間或用代碼加入，最多 8 人一起飛行 |
| 地圖 | 查看各地標、飛行環及自己目前的位置與航向；開啟地圖時飛行仍會繼續 |
| 右側引擎拉桿 | 向上增加、向下減少推力；可與飛行搖桿同時操作 |
| 起落架／G | 放下或收起輪子；在地面上需先起飛才能收起 |
| FIRE 按鈕 | 點按射擊、按住連射；可與飛行搖桿同時操作 |
| 切換視角 | 切換戰機後方與機首視角 |
| W/A/S/D 或方向鍵 | 與搖桿相同的飛行控制 |
| 空白鍵 | 按住連射 |
| V / R | 切換視角／重新開始 |

搖桿回中時機翼會逐漸擺平，機頭角度會維持，可反向推搖桿調整。遊戲畫面支援多點觸控，並停用遊戲區域的雙擊及雙指縮放。這是偏向易操作的簡化飛行模型。

沿起飛時的北方航線，可找到四個飛行環。每次飛行各環限計一次；重新起飛會重置計數。地圖上還有三條約在 600–1,350 公尺高度的彩色蜿蜒隧道，可從任一端飛入。隧道壁、摩天輪的輪框、輻條、座艙與支架，以及雲霄飛車的軌道和支架都有碰撞。擦撞會依碰撞位置與力道累積損傷並改變飛行姿態；嚴重損傷才會解體，碎片保留撞擊後的速度，並在冒火冒煙後延遲爆炸。飛行環仍可穿越，地形和海面也有碰撞。

降落前放下起落架，等輪子完全放下，讓機身貼合下方地形並降落到陸地。只要與接觸位置地面的夾角夠小，即使高速也能平穩落地；角度過大或在海面接地仍會墜毀。落地滑行時機身會跟著坡度調整；可用左右搖桿轉向、降低推力減速；加大推力，速度達約 234 km/h 時向上拉高機頭可再次起飛。

## 執行

使用 Node.js 22.13 以上版本，不需安裝套件。在專案根目錄啟動遊戲伺服器：

```sh
npm start
```

在瀏覽器開啟 `http://localhost:8080`。多人遊玩時，所有玩家必須連到同一個可互相存取的伺服器網址；房主建立房間後分享代碼或邀請連結。此 Node 伺服器的房間狀態保存在記憶體，伺服器重新啟動後會清除，且應使用單一伺服器程序。純靜態託管可執行單人模式，但需要額外的多人 API 才能連線。

瀏覽器支援 WebGL 時使用硬體加速；無法使用 WebGL 時則改以 Canvas 進行 3D 投影，效能會依裝置而異。程式與 3D 場景不依賴外部套件；介面字型在連線時會自動載入，無網路時使用系統字型。

執行飛行操控測試：

```sh
npm test
```
